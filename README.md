# Password Manager V2

Локальный менеджер паролей для Windows с зашифрованным хранилищем, мастер-паролем,
автоблокировкой и резервными копиями.

## Возможности

- шифрование vault с помощью AES-256-GCM;
- получение ключа из мастер-пароля через Scrypt с индивидуальной солью;
- создание, поиск, просмотр, изменение и удаление записей;
- генератор паролей с гарантированным набором групп символов;
- автоматическая блокировка после периода бездействия;
- автоматическая очистка буфера обмена через 30 секунд;
- транзакционный импорт CSV;
- зашифрованные резервные копии и проверка копии перед восстановлением;
- безопасная миграция старого `records.json`.

> [!IMPORTANT]
> Мастер-пароль не сохраняется и не восстанавливается. Потеря мастер-пароля означает
> потерю доступа к vault и всем его резервным копиям.

## Установка для разработки

Требуется Python 3.14.

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
```

Если команда `py` отсутствует, укажите полный путь к установленному Python 3.14.

## Запуск

```powershell
.\.venv\Scripts\pythonw.exe password_manager_app.py
```

При первом запуске приложение предложит создать мастер-пароль длиной не менее 12 символов.

## Где хранятся данные

По умолчанию на Windows:

```text
%APPDATA%\PasswordManagerV2\vault.pm2
%APPDATA%\PasswordManagerV2\vault.pm2.bak
%APPDATA%\PasswordManagerV2\vault.pm2.pre-restore.bak
%APPDATA%\PasswordManagerV2\settings.json
```

Для portable-размещения или тестов каталог можно задать переменной окружения
`PASSWORD_MANAGER_DATA_DIR` до запуска приложения.

`vault.pm2.bak` содержит предыдущее зашифрованное состояние. Дополнительные копии можно
создать на вкладке «Настройки».

Перед восстановлением приложение сохраняет заменяемый vault в
`vault.pm2.pre-restore.bak`. После смены мастер-пароля автоматическая `.bak`-копия
перешифровывается новым паролем.

## Миграция старых данных

Если при первом запуске рядом с программой найден непустой `records.json`, приложение
предложит миграцию. Последовательность операции:

1. Все старые записи читаются и проверяются.
2. Создаётся новый зашифрованный vault.
3. Создаётся зашифрованная копия `backups\legacy-migration.pm2`.
4. Только после этого открытый `records.json` удаляется.

Перед миграцией рекомендуется самостоятельно сохранить исходный файл на отключаемом носителе.

## Импорт CSV

Поддерживаются распространённые названия колонок:

| Поле | Допустимые заголовки |
| --- | --- |
| Имя | `name`, `record_name`, `title` |
| Сервис | `service`, `service_name`, `name` |
| Логин | `username`, `login`, `user` |
| Пароль | `password`, `pass` |
| URL | `url`, `website`, `url_link_service` |
| Заметка | `note`, `notes`, `comment` |

Импорт транзакционный: если хотя бы одна строка некорректна, ни одна запись не сохраняется.

## Тесты и проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m ruff check .
```

Тесты используют только временные каталоги и не открывают пользовательский vault.

## Сборка Windows

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[build]"
.\build.ps1
```

Результат:

```text
dist\PasswordManagerV2\PasswordManagerV2.exe
```

## Ограничения безопасности

- Это локальное приложение, а не синхронизируемое облачное хранилище.
- После разблокировки пароли присутствуют в памяти процесса и доступны вредоносной программе
  с правами текущего пользователя.
- Очистка буфера обмена выполняется только если его содержимое не было заменено пользователем.
- Проект не проходил независимый криптографический аудит. Для наиболее критичных корпоративных
  учётных данных используйте продукт с независимым аудитом и централизованным управлением.

# Changelog

## 1.1.0

- Ручная проверка обновлений в настройках и переход на GitHub Releases за установщиком.

## 1.0.0 — in development

### Added

- зашифрованное AES-256-GCM хранилище с Scrypt;
- мастер-пароль, экран блокировки и автоблокировка;
- полный CRUD, поиск, генератор и безопасное копирование;
- транзакционный CSV-импорт и зашифрованные резервные копии;
- автоопределение CSV Chrome/Edge/Brave/Opera, Firefox и Safari с окном прогресса;
- вертикальная компоновка окон и автоматическое добавление `https://` к адресу сайта;
- пустые поля записей и вычисление имени по сайту или логину;
- ускоренный список с порционной отрисовкой, счётчиком и быстрым копированием;
- минимум 8 символов, компактная компоновка, контрастные Light-кнопки и DPI-коррекция;
- установщик Windows с выбором папки и новое имя приложения `passwordSafe`;
- миграция старого открытого `records.json`;
- автоматические тесты, Ruff, CI и Windows-сборка.

### Changed

- пользовательские данные перенесены из рабочего каталога в `%APPDATA%\PasswordManagerV2`;
- новые vault создаются в `%APPDATA%\passwordSafe`, существующие vault из старой папки подхватываются автоматически;
- файловая и UI-логика разделены;
- ошибки валидации теперь отображаются без очистки формы.

### Removed

- хранение и логирование паролей открытым текстом;
- неработающие заглушки кнопок и устаревшие JSON helper-модули.
